# Restaurant Glishoru — Demo-Projekt

Eine eigenständige, traditionell-moderne Demo-Website für das Restaurant Glishoru in Glis.

> Dies ist ein Portfolio- und Demonstrationsprojekt, nicht die offizielle Website des Restaurants.

## Lokal starten

```bash
npm install
npm run dev
```

Die Restaurant-Seiten liegen unter `/glishoru`; die Startseite leitet automatisch dorthin weiter.
